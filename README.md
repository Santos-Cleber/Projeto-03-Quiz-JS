# Projeto 04 — Quiz JS

Quiz interativo de JavaScript com preenchimento de lacunas em blocos de código.

## Sobre o projeto

O usuário lê a pergunta, analisa as alternativas e digita o método correto diretamente no bloco de código. Ao confirmar, recebe feedback imediato com explicação sobre o método.

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades

- 5 questões sobre métodos JavaScript
- Verificação de resposta com feedback visual
- Pontuação em tempo real
- Explicação da resposta correta
- Navegação automática entre questões

## Como rodar

Abra o arquivo `index.html` no navegador.
